# Projeto de previsão de sobreviventes do Titanic

O projeto utiliza-se da base de dados do [Kaggle](https://www.kaggle.com/competitions/titanic/overview)
e tem como objetivo criar um modelo preditivo que, a partir da característica fornecida das pessoas,
deverá prever se a mesma iria sobreviver ou não ao acidente envolvendo o navio Titanic.

## Ferramentas
Para o projeto, será utilizado as seguintes ferramentas:

```
Python 3.12.3
Pandas 3.0.0
Numpy 2.4.2
Seaborn 0.13.2
Matplotlib 3.10.8
Plotly 6.5.2
Scikit-learn 1.8.0
```
